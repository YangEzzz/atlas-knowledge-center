# 个人账户信息流程草案

状态：2026-10-15 已实现首版。用户已确认使用当前有效会话读取密码，回收站保留 7 天。

2026-10-16：扩展工具账号。每条记录只关联一个项目或一个工具，不可在编辑时迁移归属。工具导航的“我的账号”进入对应工具的个人列表，侧栏汇总页统一展示，并标明“项目 / 工具”；汇总页新增时可选择关联类型并搜索对象。工具账号使用工具当前公开 URL 作为入口，不允许提交其他工具的 URL。所有密码、备注、删除与恢复操作继续限定本人。

## 依据与范围

PRD 第 10 节规划了仅本人可见的私有笔记，包含测试账号、后台账号备注；原方案是一份按用户与项目隔离的文本。本草案建议将个人账户信息单独结构化，一个用户在一个项目下可维护多条账号，方便查找和复制。通用私有笔记作为独立能力后续处理。

## 入口

- 项目详情增加「我的账号」Tab，只展示当前登录用户在该项目下的账号。
- 侧栏「我的空间」增加「我的账号」，汇总本人的记录，支持按项目、环境和名称筛选。
- 账号可关联项目下的某个资源入口，选择后展示对应访问地址。不同项目的公开资源接口不返回私人账号。
- 工具导航每行提供“我的账号”入口，工具下支持多账号；`/my-accounts?toolId=…` 仅筛选本人在该工具中的账号。工具公开列表和详情不附带私人账号信息。

## 新增

1. 从项目「我的账号」点击「添加账号」；项目自动带入。
2. 填写账号名称、环境、用户名，选填密码、关联资源入口、私人备注。
3. 密码默认遮蔽，可临时显示；明确标注备注也仅本人可见。
4. 点击保存，成功后返回账号列表；失败保留本次输入并允许重试，不在浏览器本地存储密码草稿。

字段建议：账号名称、所属项目、用户名必填；环境可选线上/测试/其他；密码、关联入口和私人备注选填。允许同项目多账号，未填写密码表示未保存密码。

## 查看与使用

列表展示名称、项目、环境、用户名、关联入口和更新时间；有密码时仅显示固定遮罩，不泄露密码长度。

- 「复制用户名」直接复制用户名。
- 「显示密码」或「复制密码」时单独向服务端请求，重新检查所有权；列表接口不下发密码。
- 显示密码 15 秒后自动隐藏；离开页面、关闭弹层或退出登录时清除页面中的已解密密码。
- 「打开入口」打开关联 URL，不将用户名或密码拼入地址，不自动提交登录。
- 剪贴板复制后提示成功；不承诺可靠自动清空系统剪贴板。

## 编辑与删除

编辑时加载普通字段，密码不预填：保持原密码、修改密码、清除已存密码为明确的三种状态。修改密码才出现新密码输入，清除须确认，避免空输入误删已有密码。

删除前显示账号名称并确认，不在确认弹层展示密码。仅本人可见的回收站保留 7 天，到期不能查看或恢复，清理任务在启动时及每小时执行物理删除。项目已删除时账号暂停使用；先恢复项目，才能恢复其账号。账号不因项目软删除而自动进入回收站，用户仍可从账号回收站处理已主动删除的记录。

工具软删除与项目软删除采用相同规则：账号暂停访问，工具恢复后才可继续使用或恢复账号；工具的“停用”状态仅影响工具导航的打开操作，不删除或转移个人账号。

## 权限与保存

- 记录的 owner 由服务端从登录会话取得，不能由客户端指定。所有读、改、删、恢复和密码读取均限定本人，防止猜测 ID 越权。
- 应用管理员不因角色获得查看他人账号的入口或接口权限。这是应用访问控制，不意味着数据库或服务器运维人员在技术上绝对无法获取信息。
- 密码与私人备注使用 AES-256-GCM 加密保存，随机 nonce，认证上下文绑定账号 ID、用户 ID、项目 ID；密钥独立于数据库和代码，采用版本化 key ring，轮换时必须保留旧版本密钥。初始化将独立密钥写入 Git 忽略的服务端环境文件；备份和生产密钥管理由运维负责。标准库依据：[Go crypto/cipher](https://pkg.go.dev/crypto/cipher#NewGCMWithRandomNonce)。
- 私人备注也可能包含敏感信息，应与密码一样保护存储内容。
- 工具账号使用独立的认证上下文前缀 `atlas-account:tool:v1`，绑定账号 ID、用户 ID、工具 ID；项目账号保留原 `atlas-account:v1` 格式，既有密文无需重写或换密钥。
- 账号信息不进入公共搜索、公共文档、导出、项目分享和通用审计正文。不记录密码、备注正文或密文到日志。
- 密码响应禁止缓存；生产环境通过 HTTPS 传输。退出或会话失效后关闭私人信息页面状态。
- 用户确认显示/复制密码使用当前有效登录会话；沿用 CSRF 和 Helios 有效身份校验，不追加二次认证弹窗。
