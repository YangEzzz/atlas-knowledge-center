# 我的入口

2026-10-16 按用户确认方案实施。

## 使用

- 我的空间调整为“我的入口 / 我的账号 / 最近访问”。旧 `/favorites` 重定向到 `/my-entries`。
- 我的入口汇总公共项目、文档、工具收藏和私人项目/工具入口。私人入口仅名称、HTTP/HTTPS 网址必填，支持分组、加密私人备注、置顶、来源筛选和每页 24 条的分页。
- 卡片提供打开、复制、我的账号、置顶和编辑；公共记录取消收藏只移除自己的引用，公共资料仍在原页面维护。
- 保存新入口可继续添加账号。账号表单的关联类型新增“私人入口”，支持搜索已有入口或就地新建；新建完成后保留已经填写的账号内容并自动选择新入口。
- 修改私人入口的网址同步其账号的打开地址，不改变密码或归属。

## 收藏迁移

旧收藏原来位于按用户隔离的浏览器 localStorage。登录后的首次同步将旧项目、文档、工具引用分批幂等导入服务器；导入成功并读取服务器记录后，才写入该用户的迁移标记。浏览器保留旧收藏备份，迁移失败保留原记录并允许重试。完成迁移后以服务器为准，避免旧设备缓存复活已取消的收藏。

公共名称和网址在读取时由原内容解析；分组、置顶和私人备注按用户独立保存。已删除或停用的公共内容保留为不可用引用，不信任浏览器提供的导航地址。

## 隐私与生命周期

私人入口和公共引用的个人元数据均存于 `personal_entries`，所有操作由会话用户限定。备注使用现有版本化 key ring 和 AES-GCM 加密，认证上下文为 `atlas-entry:v1:user:id`，不写入浏览器持久化缓存或日志。密码继续只在按需接口读取。

账号新增 `entry_id`，与项目、工具关联三选一；私人入口账号使用 `atlas-account:entry:v1` 前缀，既有项目/工具密文格式不变。

删除私人入口会在事务中将其当前有效账号一并移入回收站，标记 `entry_cascade`。恢复入口仅恢复带该联动标记的账号，不恢复此前单独删除的记录。入口与联动账号保留 7 天，过期不可恢复；清理沿用启动及每小时任务。父入口锁与账号保存/恢复事务协调，避免删除期间新增或恢复孤立账号。

## 部署

在 `apps/api` 执行 `go run ./cmd/migrate-personal-entries`，创建入口表、公共引用唯一索引，新增账号入口关联字段及联动标记，并扩展三选一约束。当前配置的 `atlas_db` 已执行；现有账号、密码密文和密钥未改变。本地后端已重启并返回健康状态 200。其他环境须先执行迁移再部署后端及前端。
