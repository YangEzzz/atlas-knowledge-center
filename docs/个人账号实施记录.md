# 个人账号实施记录

2026-10-15，依据用户确认的个人账号流程开发。

## 功能与入口

- 项目详情「我的账号」：所属项目自动带入，支持多账号、环境、用户名、关联入口与私人备注。
- 侧栏「我的账号」汇总个人记录，按名称、用户名或项目搜索，按环境筛选，服务端每页 12 条。
- 新增、编辑、密码保留/修改/清除、复制用户名、按需显示/复制密码、删除确认、回收站恢复。
- 密码显示 15 秒后隐藏，失焦、页面隐藏、离开页面或用户会话改变时清理已显示密码。编辑的敏感输入不写入浏览器持久化存储。
- 取消、离开页面或切换项目 Tab 时，未保存修改先确认；失败保留输入。通过 revision 拒绝过期更新、删除。
- 已替换失效资源入口时，编辑账号可重新选择或取消关联；仅允许关联当前项目中有效的 HTTP(S) 资源地址。

## 数据与权限

表 `accounts` 保存 user_id、project_id、名称、环境、用户名、资源 URL、密文、has_password、revision 和时间/软删除标记。密码与备注一起加密；不以明文列保存，列表和普通项目 API 不含密码或私人备注。

所有账号接口从服务端登录会话取得 userID，读写、恢复和密码读取均按 user_id 限定，无管理员越权分支。接口响应 no-store；密码通过带 CSRF 校验的 POST 单独读取，现有 Helios 中间件会重新验证有效身份。API 不记录秘密正文；本模块关闭 ORM SQL 参数日志，错误响应不回传数据库细节。

采用 Go 标准库 AES-256-GCM 随机 nonce，AAD 绑定用户、项目、账号，防止密文跨记录搬用。版本化密钥环支持保留旧密钥读取旧数据；此版本没有自动重加密/轮换界面。

删除 7 天后立即从回收站查询/恢复范围排除；启动时及每小时物理清理，到期后最多约 1 小时完成数据库删除。历史数据库备份中的密文遵循运维备份保留策略，不承诺同步销毁全部备份。

项目软删除后账号不能使用或恢复，恢复项目后恢复访问；私人账号的删除与项目删除独立。

## 初始化与部署

在 apps/api 执行 `go run ./cmd/setup-accounts`：限定 atlas_db，创建本功能表；未配置密钥且没有旧账号时生成独立 32 字节密钥，持久化到被 Git 忽略的服务端 `.env` 或 `.env-production`，不输出密钥。已有账号但丢失密钥时拒绝生成新密钥，必须先恢复原配置。

环境变量：`ACCOUNT_KEY_ID` 是当前密钥版本，`ACCOUNT_KEYS` 是版本到 base64 密钥的 JSON 对象，`ACCOUNT_REVEAL_POLICY=session` 使用当前有效会话读取密码。缺少或错误的密钥配置时账号接口返回 503，不回退到明文。生产需配置 HTTPS、限制环境文件权限，并将密钥与数据库分开备份。遗失全部旧密钥将无法解密旧记录。

本地已初始化账号表、生成独立密钥并重启 API。正式账号内容需由用户登录后录入。

## 验证

- Go 单元测试覆盖随机密文、原文往返、错误上下文、篡改密文、弱密钥拒绝和保留旧版本密钥。
- atlas_db 事务回滚测试覆盖保存/保留/清除、私人备注加密、列表无秘密、跨用户和管理员隔离、过期更新冲突、删除恢复、超过 7 天不可恢复及清理。
- HTTP 测试覆盖匿名拒绝、创建、列表不泄露、no-store、跨用户读取拒绝、密码按需读取及输入校验。
- 浏览器开发回归使用真实 Vue 页面和内存示例适配器，覆盖项目内新增、汇总页编辑、密码显示、删除确认、回收站恢复、未保存确认和保存失败保留输入；390px 检查无横向溢出，表单可滚动。
- 未用真实用户密码进行浏览器验收；生产密钥备份、轮换演练和完整读屏器测试不在本次本地验证范围。
