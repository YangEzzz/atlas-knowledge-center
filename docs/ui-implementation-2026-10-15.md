## 已实施

- 统一系统字体、品牌色与深色操作色、浅蓝画布、白色内容面、卡片/控件圆角、焦点和滚动条。
- 重建侧栏、顶部搜索、移动导航；首页优先展示常用项目、环境与仓库入口、公司工具、最近文档与访问记录。

- 保留既有登录和数据权限，不增加虚构的服务健康状态、私有笔记或审计入口。

每个入口增加选填 `remark`，由项目编辑表单提交并在详情地址下展示，空值不占位，多行文本保留换行。旧记录默认为空字符串。

数据库使用 `apps/api: go run ./cmd/migrate -entry-remark` 做可重复的单列增量迁移，仅允许 atlas_db；本地已执行并重启后端。部署已有环境时需要先执行此迁移。

前端生产构建、全部 Go 测试通过；数据库回滚测试覆盖备注保存和清空，服务测试覆盖去空白及响应映射。浏览器回归确认多行备注展示、编辑回填。上述浏览器检查仍使用开发示例适配器。

本次浏览器回归验证布局和交互状态，并非真实账号下的完整 CRUD 验收；没有声称已验证真实新增、编辑、删除成功链路。登录真实账号、实际保存和真实网络中断下的数据恢复仍需要业务验收。尚未人工覆盖 200% 缩放、完整读屏器、系统强制颜色和减少动效设置；相应 CSS 规则已保留。
