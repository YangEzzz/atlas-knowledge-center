# Atlas 研发知识中心 MVP 开发任务拆分

## 1. 文档说明

本文档用于将 Atlas 研发知识中心 MVP 拆分为可开发、可联调、可测试的任务清单。任务基于以下文档：

- `PRD.md`
- `页面原型说明.md`
- `数据模型设计.md`
- `接口清单.md`
- `prototype.html`

产品采用单应用模式，不拆分前后台。项目、资源入口、文档、工具导航均支持就地维护；管理中心只承载低频能力。

## 2. MVP 范围

### 2.1 P0 必须完成

- 当前用户信息
- 首页基础展示
- 全局搜索
- 项目库
- 项目详情
- 项目增删改查
- 项目负责人维护
- 项目资源入口增删改查
- 文档增删改查
- 文档版本列表和恢复
- 工具导航增删改查
- 收藏
- 最近访问
- 用户搜索
- 字典配置读取

### 2.2 P1 建议完成

- 文档图片上传
- 我的私有笔记
- 文档模板
- 回收站
- 操作审计
- 系统配置写入
- 文档过期标记

### 2.3 P2 暂不纳入 MVP

- 权限系统深度对接
- GitLab 自动同步
- 企微通知
- 文档评论
- 文档反馈
- 管理层视图
- 项目状态管理

## 3. 建议里程碑

### 3.1 M1：基础骨架与项目资料

目标：

- 跑通应用基础框架。
- 完成项目库、项目详情、资源入口。
- 让研发能先找到项目和地址。

包含：

- 前端应用骨架
- 路由与布局
- 用户信息
- 字典读取
- 项目列表
- 项目详情
- 项目创建、编辑、删除
- 项目负责人选择
- 资源入口列表
- 资源入口创建、编辑、删除

### 3.2 M2：文档能力

目标：

- 支持 Markdown 文档沉淀。
- 支持文档查看、编辑、版本历史和恢复。

包含：

- 文档库
- 项目详情文档 Tab
- 文档详情
- 文档编辑
- 文档版本历史
- 文档版本恢复
- 文档过期标记

### 3.3 M3：效率能力

目标：

- 提升研发日常使用效率。

包含：

- 首页聚合
- 全局搜索
- 收藏
- 最近访问
- 工具导航
- 我的私有笔记

### 3.4 M4：管理与收尾

目标：

- 补齐低频管理能力和上线质量。

包含：

- 图片上传
- 文档模板
- 回收站
- 操作审计
- 系统配置
- 联调修复
- 测试验收
- 上线准备

## 11. 风险与注意事项

### 11.1 内容维护风险

风险：

- 没有明确维护人时，系统可能变成新的信息堆积处。

建议：

- 第一批项目录入时指定负责人。
- 项目详情展示资料完整度。
- 文档过期标记提醒维护。

### 11.2 搜索质量风险

风险：

- 搜索不好用会直接影响使用频率。

建议：

- 项目必须支持别名和关键词。
- 文档保存时提取纯文本。
- 搜索结果按对象分组。

### 11.3 权限风险

风险：

- 第一版不做复杂权限，但后续会对接权限系统。

建议：

- 从第一版开始保留按钮权限和接口权限的判断位置。
- 数据表保留 `visibility`、`permission_scope` 等字段。

### 11.4 敏感信息风险

风险：

- 用户可能在公共文档中填写账号密码。

建议：

- 公共文档中强调只写申请方式，不写共享密码。
- 私有笔记只对本人可见。
- 后续可增加敏感词提醒。
