# Atlas 研发知识中心接口清单

## 1. 文档说明

本文档描述 Atlas 研发知识中心 MVP 阶段的接口设计。接口采用 REST 风格示例，不绑定具体后端框架。实际开发时可根据团队规范调整 URL、鉴权方式、分页格式和响应结构。

## 2. 通用约定

### 2.1 基础路径

```text
/api/v1
```

### 2.2 认证

第一版默认接入公司内部登录态或网关认证。接口层假设可以获取当前用户信息。

后续对接权限系统时，在接口层增加按钮权限、数据权限和管理权限校验。

### 2.3 通用响应结构

```json
{
  "code": 200,
  "message": "ok",
  "data": {}
}
```

### 2.4 分页响应结构

```json
{
  "code": 200,
  "message": "ok",
  "data": {
    "list": [],
    "page": 1,
    "pageSize": 20,
    "total": 100
  }
}
```

### 2.5 通用错误码

| code | 说明 |
|---:|---|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未登录 |
| 403 | 无权限 |
| 404 | 数据不存在 |
| 409 | 数据冲突 |
| 500 | 服务异常 |

### 2.6 通用对象类型

收藏、最近访问、审计等接口使用统一对象类型：

- `project`：项目
- `project_resource`：资源入口
- `document`：文档
- `public_link`：工具导航

## 3. 当前用户接口

### 3.1 获取当前用户

```http
GET /api/v1/auth/me
```

用途：

- 获取当前登录用户信息。
- 获取当前用户在系统内可见的基础能力。

响应：

```json
{
  "id": "10001",
  "username": "wangfe",
  "displayName": "王前端",
  "avatarUrl": "",
  "roles": ["user", "editor"],
  "permissions": ["project:create", "document:update"]
}
```

## 4. 首页接口

### 4.1 获取首页聚合数据

```http
GET /api/v1/home/overview
```

用途：

- 首页一次性获取我的常用、最近访问、工具导航、项目总览和最近更新。
- MVP 可按需拆分为多个接口；聚合接口便于首页快速渲染。

响应字段：

```json
{
  "favorites": [],
  "recentVisits": [],
  "publicLinks": [],
  "projects": [],
  "recentUpdates": []
}
```

## 5. 搜索接口

```http
GET /api/v1/search?q=云手机&types=project,project_resource,document,public_link&page=1&pageSize=20
```

查询参数：

| 参数 | 必填 | 说明 |
|---|---:|---|
| q | 是 | 搜索关键词 |
| types | 否 | 对象类型，逗号分隔 |
| page | 否 | 页码 |
| pageSize | 否 | 每页数量 |

响应：

```json
{
  "groups": [
    {
      "type": "project",
      "label": "项目",
      "items": []
    },

      "type": "project_resource",

      "items": []
    },
    {
      "type": "document",
      "label": "文档",
      "items": []

```

搜索结果项通用字段：

```json
{
```

## 10. 文档资源接口

### 10.1 上传文档图片

```http
POST /api/v1/document-assets
Content-Type: multipart/form-data
```

表单参数：

| 参数 | 必填 | 说明 |
|---|---:|---|
| file | 是 | 图片文件 |
| documentId | 否 | 文档 ID，创建文档前上传可为空 |

响应：

```json
{
  "id": "1",
  "url": "https://cdn.company.local/assets/xxx.png",
  "fileName": "deploy.png",
  "mimeType": "image/png",
  "fileSize": 123456,
  "markdown": "![deploy.png](https://cdn.company.local/assets/xxx.png)"
}
```

限制：

- 支持 jpg、png、webp、gif。
- 单张图片默认不超过 10MB。

## 18. 系统配置接口

### 18.1 获取配置列表

```http
GET /api/v1/system-configs?group=project_type&enabled=true
```

响应列表项：

```json
{
  "id": "1",
  "configGroup": "project_type",
  "configKey": "user_client",
  "configValue": "user_client",
  "label": "用户端",
  "description": "",
  "isEnabled": true,
  "sortOrder": 10
}
```

### 18.2 批量获取字典配置

```http
GET /api/v1/dictionaries?groups=project_type,resource_type,document_type
```

响应：

```json
{
  "projectType": [],
  "resourceType": [],
  "documentType": []
}
```

### 18.3 创建配置

```http
POST /api/v1/system-configs
```

请求体：

```json
{
  "configGroup": "project_type",
  "configKey": "user_client",
  "configValue": "user_client",
  "label": "用户端",
  "description": "",
  "isEnabled": true,
  "sortOrder": 10
}
```

### 18.4 更新配置

```http
PUT /api/v1/system-configs/{configId}
```

### 18.5 停用配置

```http
POST /api/v1/system-configs/{configId}/disable
```

### 18.6 启用配置

```http
POST /api/v1/system-configs/{configId}/enable
```
