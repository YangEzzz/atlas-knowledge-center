# Atlas 研发知识中心页面原型说明

## 1. 文档说明

本文档用于描述 Atlas 研发知识中心第一版的页面结构、模块布局、核心交互和空状态。当前阶段以文字线框图为主，不包含具体视觉设计。

产品采用单应用模式，不拆分前后台。项目、资源入口、文档和工具导航均在对应页面就地维护；管理中心只承载文档模板、回收站、操作审计、系统配置等低频功能。

## 2. 全局布局

### 2.1 顶部导航

顶部导航在所有页面保持一致。

左侧：

- 产品名称：Atlas 研发知识中心
- 主导航：首页、项目库、文档库、工具导航、我的收藏、最近访问、管理中心

右侧：

- 全局搜索入口
- 当前用户信息
- 可选：快捷新建按钮

### 2.2 全局搜索

全局搜索建议支持两种入口：

- 顶部导航中的搜索框或搜索按钮
- 首页中的大搜索框

搜索范围：

- 项目名称
- 项目别名和关键词
- 资源入口名称
- 资源入口 URL
- GitLab 仓库名
- 文档标题
- 文档正文
- 负责人姓名

搜索结果按类型分组：

- 项目
- 资源入口
- 文档
- 负责人

搜索结果项需要展示命中的关键信息。例如资源入口结果应展示所属项目、入口类型、入口名称和 URL。

### 2.3 权限预留

第一版不做复杂权限控制，但页面需要按能力预留按钮显隐：

- 无编辑权限：只展示查看、打开、复制、收藏。
- 有编辑权限：展示新增、编辑、删除、恢复、版本历史等操作。
- 管理权限：展示管理中心入口和配置类操作。

## 3. 首页

### 3.1 页面目标

首页用于让研发人员快速找到项目、地址、仓库、文档和常用系统入口。

### 3.2 页面结构

```text
首页
├── 全局搜索区
├── 我的常用
├── 最近访问
├── 工具导航
├── 项目总览
└── 最近更新
```

### 3.3 全局搜索区

位置：

- 页面顶部主体区域。

内容：

- 大搜索框
- 搜索占位文案：搜索项目、GitLab、测试地址、线上地址、文档或负责人
- 可选快捷筛选：项目、资源、文档

交互：

- 输入关键词后实时展示建议，或按回车进入搜索结果页。
- 命中资源入口时，可直接打开或复制链接。
- 命中文档时，进入文档详情页。
- 命中项目时，进入项目详情页。

### 3.4 我的常用

展示当前用户收藏的高频内容。

内容类型：

- 项目
- 资源入口
- 文档
- 工具导航

展示方式：

- 卡片或紧凑列表。
- 每项展示名称、类型、所属项目、最近更新时间。

操作：

- 打开
- 复制链接，适用于入口类内容
- 取消收藏

空状态：

- 文案：暂无收藏内容
- 引导：可在项目、资源入口、文档或工具导航中点击收藏

### 3.5 最近访问

展示当前用户最近访问过的内容。

内容类型：

- 项目
- 文档
- 资源入口
- 工具导航

展示字段：

- 名称
- 类型
- 所属项目，可选
- 访问时间

交互：

- 点击进入对应详情或打开对应链接。

空状态：

- 文案：暂无最近访问记录

### 3.6 工具导航

展示公司级常用系统入口。

示例：

- GitLab
- 发布平台
- 监控平台
- 日志平台
- 需求平台
- 测试平台
- API 平台

展示字段：

- 名称
- 类型
- 说明

操作：

- 打开
- 复制链接
- 收藏

### 3.7 项目总览

用于帮助新人或不熟悉项目的人浏览公司项目。

展示方式：

- 按项目类型分组，或以项目卡片网格展示。
- 第一版不使用所属业务作为核心维度。

项目卡片字段：

- 项目名称
- 项目类型
- 项目简介
- 前端负责人
- 后端负责人
- 测试负责人
- 收藏状态

操作：

- 点击进入项目详情。
- 收藏项目。

### 3.8 最近更新

展示最近被维护过的项目、资源入口和文档。

展示字段：

- 名称
- 类型
- 更新人
- 更新时间
- 更新摘要，可选

## 4. 项目库

### 4.1 页面目标

项目库用于浏览、搜索和创建项目。

### 4.2 页面结构

```text
项目库
├── 标题与新建项目按钮
├── 筛选区
├── 项目列表
└── 分页或加载更多
```

### 4.3 筛选区

筛选条件：

- 关键词
- 项目类型

项目类型：

- 前端
- 后端
- 后台
- 用户端
- 官网
- 移动端
- 小程序

关键词搜索范围：

- 项目名称
- 项目别名和关键词
- 项目简介
- 负责人姓名

### 4.4 项目列表

展示方式：

- 推荐使用表格或紧凑卡片。
- 内部工具优先保证扫描效率。

展示字段：

- 项目名称
- 项目类型
- 项目简介
- 前端负责人
- 后端负责人
- 测试负责人
- 最近更新时间
- 收藏状态

操作：

- 查看详情
- 收藏
- 编辑
- 删除

### 4.5 新建项目

入口：

- 项目库页面右上角的新建项目按钮。

表单字段：

- 项目名称，必填
- 项目类型，必填
- 项目别名和关键词，可选
- 项目简介，可选
- 前端负责人，可选，支持多个
- 后端负责人，可选，支持多个
- 测试负责人，可选，支持多个

保存后：

- 进入项目详情页。
- 提示用户继续补充资源入口和文档。

### 4.6 空状态

无项目时展示：

- 文案：暂无项目
- 操作：新建项目

筛选无结果时展示：

- 文案：未找到匹配项目
- 操作：清空筛选条件

## 5. 项目详情

### 5.1 页面目标

项目详情页是项目资料的核心聚合页，用于集中展示和维护项目基础信息、环境入口、代码仓库、文档、个人私有笔记和变更记录。

### 5.2 页面结构

```text
项目详情
├── 项目头部
├── 快捷资源区
└── Tab 区
    ├── 概览
    ├── 资源入口
    ├── 文档
    ├── 我的私有笔记
    └── 变更记录
```

### 5.3 项目头部

展示字段：

- 项目名称
- 项目类型
- 项目简介
- 项目别名和关键词
- 前端负责人
- 后端负责人
- 测试负责人
- 更新时间

操作：

- 收藏项目
- 编辑项目
- 删除项目

### 5.4 快捷资源区

快捷资源区展示最常用的资源入口，建议固定出现在项目头部下方。

默认展示类型：

- 线上地址
- 测试地址
- GitLab 地址
- 原型地址
- API 文档地址

每个入口展示：

- 类型
- 名称
- URL 或域名摘要

操作：

- 打开
- 复制链接
- 收藏

### 5.5 概览 Tab

用于展示项目基础信息和资料完整度。

模块：

- 基础信息
- 负责人
- 资源入口摘要
- 文档摘要
- 最近变更摘要

基础信息字段：

- 项目名称
- 项目类型
- 项目别名和关键词
- 项目简介
- 创建人
- 更新时间

文档摘要：

- 已创建文档数量
- 最近更新文档
- 可能过期文档数量

### 5.6 资源入口 Tab

用于维护项目相关地址和链接。

入口类型：

- 线上地址
- 测试地址
- GitLab 地址
- 原型地址
- API 文档地址

列表字段：

- 名称
- 类型
- URL
- 说明
- 更新时间
- 创建人
- 收藏状态

操作：

- 新增资源入口
- 打开
- 复制链接
- 收藏
- 编辑
- 删除

新增或编辑表单字段：

- 名称，必填
- 类型，必填
- URL，必填
- 说明，可选
- 排序，可选

空状态：

- 文案：暂无资源入口
- 操作：新增资源入口

### 5.7 文档 Tab

用于展示和维护项目文档。

文档类型：

- 项目介绍
- 环境说明
- 部署说明
- API 说明
- 账号/权限申请说明
- 常见问题 FAQ
- 开发规范

列表字段：

- 标题
- 文档类型
- 摘要
- 更新人
- 更新时间
- 是否可能过期

操作：

- 新建文档
- 查看文档
- 编辑文档
- 查看版本历史
- 删除文档

过期规则：

- 文档超过 90 天未更新，展示“可能过期”标记。

空状态：

- 文案：暂无项目文档
- 操作：新建文档

### 5.8 我的私有笔记 Tab

用于存储当前用户在该项目下的个人备注。

内容：

- Markdown 或普通文本编辑区
- 最后保存时间

操作：

- 编辑
- 保存
- 取消

权限：

- 仅当前用户可见。
- 不进入项目公共搜索结果。
- 不展示给其他用户。

空状态：

- 文案：暂无私有笔记
- 操作：开始记录

### 5.9 变更记录 Tab

用于展示当前项目相关的操作审计。

记录范围：

- 项目创建、修改、删除、恢复
- 资源入口创建、修改、删除、恢复
- 文档创建、修改、删除、恢复

展示字段：

- 操作时间
- 操作人
- 操作类型
- 操作对象
- 变更摘要

交互：

- 可按操作对象筛选。
- 可按操作类型筛选。

### 7.2 页面结构

```text
文档详情
├── 文档头部
├── 正文阅读区
└── 右侧目录
```

### 7.3 文档头部

展示字段：

- 文档标题

- 更新时间
- 可能过期标记

操作：

- 收藏
- 编辑
- 版本历史
- 删除

### 7.4 正文阅读区

能力：

- Markdown 渲染

## 8. 文档编辑页

### 8.1 页面目标

文档编辑页用于创建和编辑 Markdown 文档。

### 8.2 页面结构

```text
文档编辑页
├── 基础信息区
├── Markdown 编辑器
└── 操作区
```

### 8.3 基础信息区

字段：

- 标题，必填
- 所属项目，必填
- 文档类型，必填
- 摘要，可选

### 8.4 Markdown 编辑器

能力：

- Markdown 输入
- 实时预览或分屏预览
- 图片上传
- 根据文档类型带出模板

图片上传：

- 支持 jpg、png、webp、gif。
- 单张图片不超过 10MB。
- 上传成功后自动插入 Markdown 图片语法。

### 8.5 操作区

操作：

- 保存
- 取消
- 预览

保存规则：

- 每次保存生成文档版本记录。
- 保存后返回文档详情页。

## 9. 文档版本历史

### 9.1 页面目标

### 9.2 展示字段

系统配置用于维护低频基础配置。

### 17.2 配置项

- 项目类型
- 资源类型
- 文档类型
- 图片大小限制
- 文档过期天数，默认 90 天

### 17.3 配置规则

- 项目类型、资源类型、文档类型支持新增、编辑、停用。
- 停用后的类型不影响历史数据展示。
- 图片大小限制默认 10MB。
- 文档过期天数默认 90 天。

## 18. 关键交互规则

### 18.1 打开外部链接

- 资源入口和工具导航默认在新标签页打开。
- 所有 URL 均提供复制链接能力。

### 18.2 收藏

- 收藏状态应在首页、项目库、项目详情、文档库、工具导航、我的收藏中保持一致。
- 用户取消收藏后，对应内容从我的收藏中移除。

### 18.3 最近访问

- 用户打开项目详情、文档详情、资源入口或工具导航时记录最近访问。
- 最近访问按用户隔离。

### 18.4 软删除

- 删除项目、资源入口、文档和工具导航时进入软删除状态。
- 已删除内容不在普通列表中展示。
- 有权限用户可在回收站恢复。

### 18.5 文档过期标记

- 文档超过 90 天未更新时展示“可能过期”标记。
- 标记只作为提醒，不影响阅读和编辑。

### 18.6 我的私有笔记

- 私有笔记仅当前用户可见。
- 私有笔记不进入全局搜索。
- 私有笔记不进入操作审计的公开内容展示，但保存动作可记录审计事件。
