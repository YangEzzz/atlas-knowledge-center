# 管理中心：模板、回收站与审计

## 范围与权限

2026-10-21 用户授权实现三个模块。面向 Atlas 的 admin / owner，管理入口、列表、详情和操作均由服务端校验。普通成员仅可读取已启用模板，用于新建文档。系统配置不在本次范围；不展示无效入口。个人账号、私人入口和私人备注不进入公共回收站或审计。

## 文档模板

- 沿用现有 wangEditor 富文本格式，支持名称、适用文档类型、正文、启用状态；新增、编辑、启停、删除、分页与筛选。
- 每个类型允许多个模板，最多一个启用；启用时在同一事务中停用同类型旧模板。使用数据库唯一约束防止并发产生多个启用项。
- 编辑采用更新时间校验，过期表单提示重新加载；删除、离开未保存表单需确认，失败保留输入。
- 新建文档自动读取当前类型的启用模板，仅填入空正文；请求返回后再次核对类型、是否已有文档、正文是否被编辑。已有文档或已填写正文不自动覆盖。无启用模板时留空，保留手动编写能力；读取失败明确提示、允许重试。
- 模板变更不影响已保存文档；删除模板无需删除历史文档。

## 回收站

- 统一展示软删除的项目、资源入口、文档、工具导航；名称/类型筛选、服务端分页，显示删除人、时间、所属项目。
- 仅提供恢复，不提供永久删除或自动清理。重复恢复返回冲突，不重复生成审计。
- 项目删除保留其子项原状态；项目恢复后原有效子项重新可用，此前单独删除的子项仍在回收站。文档列表隐藏已删除项目的文档。
- 单独恢复资源入口、文档时，父项目须有效，否则提示先恢复项目。恢复维持原 ID、内容及关联；唯一性冲突返回明确提示。
- 项目表单以入口 ID 差量保存，移除入口为软删除，不再全部物理删除重建。旧客户端无 ID 时按类型+地址匹配已有入口。

## 操作审计

- 覆盖项目、资源入口、文档、工具导航的创建、修改、删除、恢复，以及文档版本恢复、模板维护。
- 记录真实会话操作人 ID/名称快照、服务器时间、对象类型/ID/名称快照、所属项目、操作类型、变更摘要和变更字段名；不保存密码、私人备注、正文快照或完整请求。
- 业务写入与审计写入同一事务，审计失败回滚业务；失败请求、无效删除/恢复不生成成功记录。
- 审计按实际变更对象记录。仅修改两个资源入口名称时生成两条入口记录，不额外生成项目汇总记录；同时修改项目自身字段或负责人时，另生成一条项目记录，其变更字段仅列项目自身信息。
- 只读列表和详情，支持操作人、对象类型、操作类型、时间范围、关键词筛选及分页。时间输入按北京时间，记录显示 Asia/Shanghai。
- 审计从上线后开始记录，不伪造历史数据；旧记录删除人为空时显示“历史记录”。

## 验收

1. 新增/编辑/启停/删除模板，冲突表单不覆盖；新文档自动填充，已输入或已保存文档不被覆盖，快速切换类型忽略旧请求。
2. 四种对象删除后出现在回收站，恢复后以原 ID 可用；父项目删除时阻止单独恢复子项；重复恢复冲突。
3. 项目编辑保留入口 ID，移除入口可恢复；无关编辑不制造入口删除/创建记录。
4. CRUD 与审计同事务；筛选分页有效；非管理员不能通过直接接口访问管理能力。
5. 前端构建、现有测试、新增事务回滚集成测试通过；浏览器覆盖空态、错误、确认、窄屏和键盘操作。

## 已实现接口

所有接口位于 `/api/v1`，复用 Helios 会话及 CSRF 校验。

| 接口 | 用途 |
|---|---|
| GET /document-templates/active/:type | 成员读取该类型启用模板；不存在时 data 为 null |
| GET /manage/templates | 模板分页、名称/类型/启用状态筛选 |
| POST /manage/templates | 新增模板 |
| PUT /manage/templates/:id | 更新模板，含启停；必须提交原 updatedAt |
| DELETE /manage/templates/:id | 删除模板；请求体含原 updatedAt |
| GET /manage/trash | 四类公共资料统一回收站，分页与名称/类型筛选 |
| POST /manage/trash/:type/:id/restore | 恢复原对象；type 为 project / entry / document / tool |
| GET /manage/audit | 按关键词、操作人、对象类型、操作类型和 RFC3339 时间区间查询 |
| GET /manage/audit/:id | 只读审计详情 |

管理接口返回真实 400 / 403 / 404 / 409 / 500 HTTP 状态；冲突与业务失败不回传原始数据库错误。旧项目、文档、工具恢复接口及旧文档回收站接口也补充相同管理员校验。
