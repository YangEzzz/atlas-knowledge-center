# Helios 公共图片接入

文档编辑器的「上传图片」按钮及原有图片菜单使用相同上传流程，新图片以外部地址写进正文，不再编码为 Base64。历史正文保持兼容。

1. 浏览器校验图片格式与 10 MiB 限制，分块计算原始字节 MD5。
2. `POST /api/v1/images/check` 查询；命中直接插入地址，不发送文件。
3. 未命中以 FormData 向 `POST /api/v1/images/upload` 提交 `file` 和 `md5`。Atlas 重新校验实际字节、大小、格式和 MD5，再次查询后才决定是否向 Helios 上传。
4. 返回地址以 Helios 对外域名补全后写入正文。Helios 负责原子存储及并发去重，Atlas 不留第二份文件。

处理期间显示状态，可取消，保存/发布暂不可用；失败保留正文，重新选择同一文件即可重试。离开编辑器取消在途请求，迟到结果不会插入其他文档。取消不承诺删除已完成存储的公共文件。

## 鉴权

Atlas 图片接口位于已有登录与 CSRF 中间件之后。用户 ID 来自服务端会话，不接收浏览器指定的身份。

Atlas 后端以已有 `HELIOS_CLIENT_ID` / `HELIOS_CLIENT_SECRET` 做 HTTP Basic 认证，`X-Helios-User-ID` 为登录会话中的 Helios 用户 UUID。Helios 重新校验有效项目凭据、用户启用状态和项目成员关系。浏览器不接触项目密钥，不依赖 Helios 浏览器 Cookie，不放宽跨域白名单。

下游项目凭据错误映射为 503 配置错误，不当作 Atlas 会话失效；网络或异常响应返回 502。只接受 Helios 的 `/uploads/images/` 返回路径。

## 配置与部署

- `HELIOS_IMAGE_INTERNAL_URL`：后端请求 Helios 的地址，未设置时沿用 `HELIOS_INTERNAL_URL`。
- `HELIOS_IMAGE_PUBLIC_URL`：浏览器读取图片的地址，未设置时沿用 `HELIOS_BASE_URL`。
- 本地分别配置 `http://127.0.0.1:3456` 和 `http://localhost:3456`，不改变统一登录地址。
- 线上使用正式域名，先部署 Helios 的 `sso.ImageAuth`。代理需放行静态图片，允许至少 11 MiB 请求体，持久化及备份 Helios `uploads` 目录。
- 无需数据库迁移。图片公开读取，编辑器中说明用途。

## 验证

Helios 鉴权测试覆盖有效成员、缺失/无效用户、无效凭据、撤销成员、数据库故障和匿名拒绝；既有图片及并发去重测试通过。

Atlas 代理测试使用本地 HTTP 服务，覆盖新上传、命中不转发文件、会话身份传递、凭据故障、撤权、服务故障和非法 URL 拒绝。

前端 `node tests/images.test.mjs` 验证 MD5 已知值、分块计算、命中不上传、未命中 FormData、输入校验、取消和失败；生产构建通过。浏览器使用 `tests/design-preview.html?route=/documents/editor&scenario=image-error` 验证失败保留正文、同文件重试、再次上传复用地址。示例图片不写入真实文档和 Helios 存储。

未用真实用户账号保存文档或上传私人图片；线上完整登录上传仍需业务账号验收。
