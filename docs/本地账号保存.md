# 本地账号保存

业务依据：2026-10-16 用户确认“不上传账号密码、无需本地加密或解锁密码”的方案。入口名称、网址、分组仍使用现有服务器接口；关联账号独立选择保存位置。

## 使用行为

- 添加账号默认“仅此浏览器”，可以主动切换“服务器同步”。已有服务器账号不迁移。
- 卡片以所属项目、工具或私人入口名称作为标题。“用途备注”靠后选填，留空即可直接保存，旧 name 字段保留为用途备注；用户名只在明细行显示。本地及服务器 name 均允许为空，无数据库迁移。
- 本地保存账号名称、用户名、密码、账号备注、归属及地址快照。整条记录仅写入当前站点 IndexedDB，不调用账号写入、密码、删除或恢复接口；搜索词也不进入服务器请求。
- 不加密；表单明确说明共享此浏览器的人可能读取、清除网站数据会丢失、不同网址和浏览器不共享。账号密码仍默认遮蔽、按需显示并自动隐藏。没有新增独立解锁密码或加密备份功能。
- 两种来源在共享 PersonalAccounts 中统一排序分页、标明本地/服务器，可筛选。服务器故障显示来源失败说明，已有本地账号仍可查看。选择“仅此浏览器”筛选时不请求服务器账号列表。
- 编辑固定保存位置和归属，不提供悄悄上传或自动迁移。输入未保存时沿用现有关闭确认，失败保留输入。
- 删除本地账号进入同站点、同用户的本地回收站，7 天后失效，下次读取清理；恢复保持本地。入口服务器回收站只联动服务器账号，本地账号独立保留，防止其他设备删除唯一凭据。
- 退出登录清除界面明文、表单、删除确认；本地数据保留。不同 Atlas 用户 ID 在应用内分开读取。拥有浏览器控制权的人仍能读取磁盘记录，这不是对本机攻击者的安全边界。

## 实现

`utils/local-accounts.ts` 使用 accounts object store、owner 索引和原生 IndexedDB 事务；本地 UI ID 使用负数，服务器 ID 使用正数。新增使用数据库自增键，多标签编辑和删除通过事务内 revision 校验。列表不返回密码和备注；仅本地详情/密码操作返回需要的字段。失败不自动落到服务器。

`composables/personal-accounts.ts` 为共享组件提供明确的本地/服务器分发，服务器保存使用原始 AccountInput，不传本地归属展示信息。列表仅分页请求服务器元数据，搜索词不发送到服务器。登录用户变化后拒绝异步结果，组件丢弃旧请求和旧表单。

本地数据不自动跨地址迁移，不自动追踪其他设备对入口网址的修改；打开编辑时会重新读取入口资料，保存后更新本地地址快照。入口删除后可从“我的账号”继续取回本地凭据。
